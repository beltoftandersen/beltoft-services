# Beltoft Services for WooCommerce

Sell services with WooCommerce Subscriptions. A license (from Beltoft Licenses) is the entitlement; drivers provision, pause, resume and remove the service in Action Scheduler jobs.

Requires WooCommerce, WooCommerce Subscriptions and Beltoft Licenses 0.7.0 or newer.

Tests: `/root/plugin-tests/run.sh /path/to/beltoft-services`
